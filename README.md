# perpus-sman1lampasi

Sistem Informasi & Manajemen Perpustakaan Modern untuk Pustaka SMAN 1 LAMPASIO.

Repository: [https://github.com/Hamdani-150889/perpus-sman1lampasi](https://github.com/Hamdani-150889/perpus-sman1lampasi)

## Menjalankan Secara Lokal (Run Locally)

**Prasyarat:** Node.js (v18+)

1. Instal dependensi:
   ```bash
   npm install
   ```
2. Jalankan aplikasi:
   ```bash
   npm run dev
   ```
3. Buka browser pada alamat yang tertera (biasanya `http://localhost:3000`).

## Fitur Utama

- **Katalog & Inventaris Buku:** Tambah, edit, hapus, dan cari buku dengan mudah.
- **Ekspor & Impor Excel:** Templat dan data katalog buku dapat diimpor dan diekspor via berkas XLSX.
- **Manajemen Peminjaman:** Pencatatan sirkulasi peminjaman, tanggal jatuh tempo, dan denda keterlambatan.
- **Manajemen Anggota:** Pendataan siswa dan staf dengan status kartu perpustakaan aktif/nonaktif.
- **Statistik & Dashboard Interaktif:** Pemantauan buku populer, ringkasan sirkulasi, dan kategori.
